# SpectrumKit

SpectrumKit is a C#/.NET library for working with and visualizing spectral data, with a focus on hyperspectral imaging (HSI).

The project is currently under active development.

## Current Features

* Load spectral data from CSV files
* Represent individual spectra and collections of spectra
* Basic spectral data handling and normalization
* Spectrum plotting and visualization
* Wavelength-aware spectral plots
* Playground project for testing and development

## Project Structure

* **SpectrumKit** — main class library

  * `Models` — spectral data models
  * `IO` — data loading
  * `Visualization` — spectrum plotting
* **SpectrumKit.Playground** — small executable project used for testing and experimenting with the library

## Status

Early development. APIs and project structure may change as the library evolves.
